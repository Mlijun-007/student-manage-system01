# 培训机构管理系统前端项目

## 项目介绍

这是一个基于Vue.js开发的培训机构管理系统前端项目，用于管理学员、课程和班级信息。系统提供了直观的用户界面，支持学员信息的增删改查、课程管理、班级管理等功能。

## 技术栈

- **框架**: Vue.js 2.6.x
- **UI组件库**: Element UI 2.15.x
- **HTTP客户端**: Axios
- **构建工具**: Webpack 5.x
- **开发服务器**: Webpack Dev Server

## 安装步骤

### 1. 安装Node.js

确保您的计算机已安装Node.js 14.x或更高版本。您可以从官方网站下载安装包：
[https://nodejs.org/zh-cn/download/](https://nodejs.org/zh-cn/download/)

### 2. 克隆项目

```bash
git clone <项目仓库地址>
cd test01
```

### 3. 安装依赖

使用npm安装项目依赖：

```bash
npm install
```

## 运行项目

### 启动开发服务器

运行以下命令启动开发服务器：

```bash
npm run dev
```

服务器将在 `http://localhost:8080` 启动，浏览器会自动打开项目页面。

### 构建生产版本

如果需要部署到生产环境，可以运行以下命令构建生产版本：

```bash
npm run build
```

构建完成后，生成的静态文件将位于 `dist` 目录中。

## 功能说明

### 1. 学员管理
- **查看学员列表**: 显示所有学员信息，支持分页和搜索
- **新增学员**: 添加新学员信息
- **编辑学员**: 修改已有学员信息
- **删除学员**: 删除不需要的学员信息

### 2. 课程管理
- **查看课程列表**: 显示所有课程信息
- **新增课程**: 添加新课程
- **编辑课程**: 修改已有课程信息
- **删除课程**: 删除不需要的课程

### 3. 班级管理
- **查看班级列表**: 显示所有班级信息
- **新增班级**: 添加新班级
- **查看班级详情**: 查看班级内的学员信息

### 4. 数据统计
- 显示学员总数、课程总数和班级总数的统计信息

## 配置说明

### API接口配置

系统默认配置的后端API地址为 `http://localhost:8081`。如果您的后端API运行在不同的地址或端口，可以在 `App.vue` 文件中修改以下配置：

```javascript
const apiClient = axios.create({
  baseURL: 'http://localhost:8081', // 这里修改为您的后端API地址
  headers: {
    'Content-Type': 'application/json'
  }
});
```

### 模拟数据

如果没有后端API服务，系统会自动使用本地模拟数据运行。模拟数据包含了一些示例学员、课程和班级信息，以便您可以直接体验系统功能。

1. **后端服务**: 如果需要使用真实的后端API，请确保后端服务已启动并运行在配置的地址和端口上。
2. **依赖安装**: 首次运行项目前请确保已安装所有依赖。

## 常见问题

### Q: 为什么新增或删除学员失败？
A: 可能是因为后端API服务没有运行。请确保后端服务已启动，或者系统会自动切换到模拟数据模式。

### Q: 如何修改项目端口？
A: 可以在 `webpack.config.js` 文件中修改 `devServer.port` 配置。

### Q: 构建后的文件如何部署？
A: 将 `dist` 目录中的所有文件部署到您的Web服务器即可。
